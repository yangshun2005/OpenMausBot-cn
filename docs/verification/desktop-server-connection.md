# 桌面端服务器连接

在一次性 Electron 窗口中运行真实的 Settings 连接组件：

```sh
node scripts/verify-server-connection.mjs
```

使用仓库已安装的依赖，包括 Electron 二进制文件。
Linux 需要图形会话（或通过 `xvfb-run -a` 运行命令）。
脚本会自行创建回环 Vite 预览、临时 HOME 和 Electron
配置文件。它不接受任何服务器 URL，并会拦截该预览
及其启动的隔离假引擎服务器之外的请求。
它绝不会打开操作者的应用、服务器列表、凭据或浏览器配置文件。

冒烟测试挂载 `RemoteComputerSection`、`ConnectedWorkspacesSettings` 和
`DesktopWorkspaceSwitcher`，使用真实样式和 `electron/preload.cjs`。
它还会针对一次性假引擎服务器打开真实应用外壳。
它检查：

- 完整的自定义 HTTPS 配对链接（含其 12 位字符代码）原样到达
  `environments:add-from-link`，且绝不调用 companion 配对。
- 响应待处理期间，重复提交被阻止。
- 取消、拒绝和重试会恢复可用表单；Electron 的错误
  包装器从可见消息中移除。
- 桌面端 companion 模式仍通过
  `desktop-remote:pair` 发送规范化的六位代码。
- 390px 布局没有文档横向溢出。
- 托管工作区表单接受主机名/地址或配对链接以及
  可选名称。取消会保留输入；确认连接会保留
  现有列表，并从保存的连接数据中排除配对代码。
- 生产原生菜单的 Connect 项会请求 Settings；其保存的
  工作区项会派发固定 ID。Settings 可以切换连接，并
  取消或确认仅忘记一个已保存连接。
- 本地应用将 Servers 作为顶层 Settings 页面打开，即使在
  本地 provider 引导之前也是如此。原生请求还会清除过期的 Settings
  搜索，使请求的页面真正可见。
- 声明本地源之外的页面不会收到保存列表/变更
  桥接或 Node 访问权限。其工作区桥接仅包含 `state`（当前
  名称，而非列表）和 `menu`（用户在 Electron 原生菜单中选择）。
- 计算机访问默认关闭，选中的文件夹默认只读，取消
  确认不会授予任何权限，停止共享会立即更新状态。
- 功能标志缺失时，不会出现任何共享控件，包括通过
  旧的配对后深链接。随后冒烟测试仅在其一次性服务器中显式启用该标志，
  以测试未完成功能的启用路径。
- 配对后深链接会为正确的已保存工作区打开访问权限。托管
  渲染器**不会**收到 `computerSharing` 权限桥接。
- 真实配对交换会设置 Chromium 的 HttpOnly 会话 cookie。原生
  连接器使用 `session.fetch` 向真实 fixture 服务器注册，然后
  撤销注册。其 cookie 绝不会复制到渲染器 JavaScript 中。

打印的证据目录保留 `receipt.json`、`electron.log` 以及
桌面/窄屏/应用内截图。成功清理仅移除
临时 home、配置文件和服务器数据。预期的假 IPC 拒绝消息
会出现在日志中。

这验证了实际的渲染器/preload 派发，其中 fixture IPC 处理器
替代了原生确认、服务器持久化和导航。它
不证明公共 DNS/TLS 或实时计算机控制会话。原生
连接器部分确实证明了真实配对交换和 cookie 认证的
注册；文件系统和 MCP 执行见下文。
原生菜单项以编程方式选择；这不是对操作系统弹窗的
物理鼠标/键盘测试。
现有生产处理器仍执行原生确认并打开
服务器的配对页面；其 URL/状态辅助函数通过
`node --test electron/environments.node-test.mjs` 单独检查。不要将此离线
冒烟测试报告为对客户服务器的已认证连接。

## 用户流程

在启用此功能的桌面构建中，选择侧边栏搜索上方的
服务器下拉菜单 → **Connect to a server…**，或打开 **Settings →
Servers**。输入服务器的 HTTPS 地址或完整配对链接以及
可选名称。在原生对话框中确认主机，然后在该服务器上完成配对或
邮箱登录。若要在不使用 CLI 手机向导的情况下生成所有者链接，请在服务器上运行
`npx openmausbot pair --label "My desktop"`。
将此链接视为机密。现有的受限访问链接保留其限制。

选择 **This computer** 或已保存的托管工作区进行切换。每个源
保留自己的会话、机器人、聊天、provider 凭据和设置。**Forget**
会将此桌面端登出并移除其保存的连接，而非服务器的机器人
或数据。服务器必须独立保持运行。

下拉菜单在服务器自己的 UI 中渲染，因此桌面端和托管 UI
都需要更新才能使用页内控件。连接到较旧的托管
版本时，原生 **Server** 菜单仍可用于切回或打开
本地连接 Settings。远程页面无法枚举桌面端已保存的
连接，也无法直接调用切换、忘记或仅主机控件。

## 可选的计算机共享

**计算机共享默认禁用。** 例外是将 Mac
借给用户自己的 OMB Cloud home，它有独立的开关和门控；参见
`docs/cloud-pro.md` 中的 "Let my Cloud use this Mac"。
连接和切换托管工作区仍然可用，但不提供
本地文件、终端或屏幕访问。以下流程仅限维护者
验证，需在两个服务器上设置 `features.sharedComputers: true`，并非
推荐的生产设置或 Settings 开关。

配对或登录成功后，原生 **Share this computer?**
对话框提供 **Choose access** 或 **Not now**（默认）。此选择会
为该工作区身份和配对会话记住，不会在
每次切换时重复。不同的登录或服务器身份需要重新审核。
较旧的服务器需要先更新才能声明此能力。

**Choose access**，或 **Settings → Servers → Computer access**：

- 选择特定文件夹。它们默认只读；**Allow edits** 允许创建
  和哈希保护的覆盖，但不允许删除。路径保持在所选文件夹内；
  符号/硬链接以及桌面端自己的凭据/配置文件存储会被
  拒绝。每次操作的文件限制为 256 KiB。这是文件传输
  接口，不是挂载文件系统，也不是针对恶意本地进程的沙箱。
- **Unrestricted terminal** 是单独的广泛选择加入：命令以
  桌面用户身份运行，可以在这些文件夹之外读/写/删除，包括
  凭据。不继承 API-key 环境或 shell 启动文件；这
  **不会**限制命令。每次调用最长 30 秒，输出 256 KiB。
- **Computer control** 是单独的广泛选择加入：官方本地 Cua MCP
  可以观察和操作已登录的应用，超出共享文件夹边界。
  本地控制和操作系统权限必须已启用。本地资源
  租约会阻止与本地机器人轮次并发调用，并尊重人工保持。
  调用之间，其他操作者可能更改屏幕：行动前再次观察。

保存需要原生确认，指明确切的 HTTPS 工作区和
权限。共享内容可能到达该服务器的模型 provider。仅连接
工作区不会授予任何权限。

**哪些机器人可以使用它。** 借出的计算机属于其配对
会话注册它的人。在该服务器上，只有该人发起的对话
（他们自己的消息，来自已登录或配对会话，发起了该轮次）可以
列出或使用它；同一请求的延续会保留它。其他人的
对话、例程、webhook、房间、机器人的委托或对等轮次以及
机器自己的所有者通过回环都看不到计算机，已知的计算机 id
的回答与未知 id 完全相同。条目以注册
会话为键，因此没有其他会话可以接管或占用 id。服务器还会
在排队之前拒绝桌面端注册范围之外的任何操作；
桌面端仍会根据自身授权检查每个操作。
**Computer** 设置关闭的机器人无法使用借出的应用和屏幕。

**文件夹访问永远无法到达的内容。** 除了桌面端自己的数据和授权
存储之外，任何文件夹操作（读取、列出或写入）都无法到达
用户的密钥和登录存储，或自行运行代码的位置，无论
周围文件夹是如何选择的：`~/.ssh`、`~/.gnupg`、`~/.aws`、`~/.azure`、`~/.kube`、
`~/.docker`、`~/.netrc`、`~/.git-credentials`、`~/.npmrc`、`~/.pypirc`、
`~/.claude`、`~/.claude.json`、`~/.codex`、`~/.config/{gh,gcloud,op,git,fish,
autostart,systemd}`、浏览器配置文件、`~/Library/{Keychains,Cookies,
LaunchAgents,Safari}` 和 `~/.local/bin`（该列表位于
`electron/shared-computer-access.mjs` 中的 `PERSONAL_SECRETS`）。列出时它们显示为
`protected`。任何 `.git` 目录内的写入都会被拒绝，因为
git 会从其配置和 hook 运行命令。程序之后运行的其他文件
（脚本、构建文件）仍可在可写文件夹中编辑。

**Computer control** 仅提供屏幕上的工具，且对每个工具仅提供
观察或操作屏幕的参数（`electron/lent-screen-tools.mjs` 中的
`LENT_SCREEN_ARGUMENTS`，派生自驱动自己的 schema，并
对照 `electron/fixtures` 中的快照检查）。本地驱动的
其他工具（按路径将本地文件上传到页面、录制或
回放到路径、更改或更新其配置、安装二进制文件、打开
DevTools 端口、杀死进程、提升权限提示）会被拒绝并隐藏，
任何命名文件的参数也是如此
（`screenshot_out_file`、`debug_image_out`、`image_path`、作为光标
图标或要打开的 URL 的路径）、命令行或端口。未知参数会被
拒绝，绝不转发。

**活动日志。** 桌面端记录它收到的每个请求（时间、服务器、
操作、文件夹名称和相对路径、工具名称或命令文本，以及
是运行还是被拒绝）到授权旁边的 `lending-activity.jsonl`，仅所有者
可读。它只会追加（绝不通过链接）；500 条目的完整文件
会原样移到一旁为 `lending-activity.jsonl.1`。它绝不记录文件
内容、输出或键入的文本。
**Computer access** 显示该服务器的最近条目。

连接器在 Electron main 中运行，出站到配对服务器；没有
暴露的本地监听器。每个请求都需要实时配对会话加上
单独的连接器密钥。桌面端——而非服务器——会根据本地授权检查每个操作。
授权是本地、仅所有者可读的文件，不包含配对
代码。文件授权无法暴露 Electron 配置文件存储，包括这些授权。

Agent 使用 `list_shared_computers` 然后 `shared_computer`。它们收到文件夹
ID/名称，而非本地绝对路径。请求送达时以及运行期间，
机器人的轮次能力必须仍然有效。离线或不确定的操作
绝不自动重放，也绝不回退到服务器文件系统。
服务器重启会清除内存队列；桌面端会重新连接而不
重放操作。轮询不会持有工作区备份维护门。

桌面端打开期间，访问权限在工作区切换之间持续存在。**Stop
sharing**、**Forget**、撤销配对或关闭桌面端会停止
连接器。正在运行的命令会尽可能取消；Cua 已接纳的原生操作
可能已完成。重试前检查不确定的结果。休眠/离线的笔记本电脑
无法服务请求。

在重新连接已保存授权、接受同意、派发远程作业之前，
以及在现有的一秒作业租约上，会重新检查本地功能标志。
禁用或不可达的本地服务器会中止连接器；
进行中的检查可能长达其三秒请求截止时间。重新启用标志后
重启桌面端。关闭它不会清除授权，
已接纳的原生操作可能已完成。

## 连接器和权限测试

```sh
pnpm exec vitest run server/shared-computers.test.ts server/shared-computers.e2e.test.ts server/shared-computers.gate.test.ts
node --test electron/shared-computer-access.node-test.mjs electron/lending-guards.node-test.mjs
```

**Shared terminal smoke** 工作流在 Windows 上运行原生终端测试和此
真实连接器测试。它覆盖普通 cmdlet、带引号和 Unicode
命令文本、前导声明、管道、返回/退出状态和进程
撤销。Windows PowerShell 优先使用自己的模块，同时保留
其余已解析的模块搜索路径。不引入新的命令限制或审批
提示；现有授权、超时和取消保持不变。

端到端测试启动一个**真实隔离服务器**，配对桌面端，打开
一个假模型轮次，并使用该轮次的能力启动**真实 agents MCP 进程**。
它通过真实出站连接器读取/编辑 fixture 文件并运行无害的终端
命令。它检查只读拒绝、遍历拒绝、按会话/密钥所有权、cookie CSRF、
远程会话的本地控制门拒绝、进行中撤销和持久访问关闭。
它在 fixture 服务器日志旁写入脱敏的 receipt。

单元测试覆盖轮次取消、离线会话、单作业投递/不
重放、主机屏幕资源租约和人工接管、路径/链接/大小限制、
受保护的桌面存储、终端取消，以及使用替身的持久官方
风格 Cua MCP 握手/图像传输。它们不操作用户屏幕，也不证明
每个受支持操作系统上的真实 Cua 操作。此配方未演练实时 VPS、
公共 HTTPS、Windows 桌面或 macOS 屏幕权限。在声称覆盖之前
单独运行那些发布冒烟检查。
