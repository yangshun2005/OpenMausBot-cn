# OpenMausMobile 隐私

OpenMausMobile 是用户自行选择并运行的 OpenMausBot 服务的配套应用。本地 Wi-Fi 和 Tailscale 连接无需 OpenMausBot 账户即可使用。用户可另行在桌面端登录，以启用可选的 **随时随地使用手机** HTTPS 连接。

## 数据处理

- iOS 应用将所选计算机地址存储在 iOS 偏好设置中，将配对令牌存储在 iOS 钥匙串中。
- iOS 分享扩展可通过私有 App Group 访问该所选计算机元数据，并通过共享钥匙串访问组访问其配对令牌。其他应用无法获取这些值。
- 计算机仍是机器人、对话记录、审批、凭据、SQLite 数据和屏幕图像的来源。OpenMausBot 的托管控制平面不存储这些内容的副本。
- 当用户在手机上完成受支持的凭据请求时，该值仅存在于原生安全输入框中，存在时间仅够用该计算机二维码所固定的公钥进行加密。加密完成后，应用立即清空该输入框。应用可能在内存中保留生成的密文，以便在响应中断后重试完全相同的操作；该密文永不持久化，应用退出时即被丢弃。仅可通过托管 HTTPS 或 Tailscale 提交，不可通过明文 LAN 或 Bonjour HTTP 提交。sidecar 和可选托管中继收到的是 HPKE 密文，而非原始值。只有已配对的打包桌面进程持有私钥：内嵌服务器解密后，通过 Electron 的私有进程通道传递该值，经由与设置相同的操作系统加密存储提交。OpenMausMobile、聊天、SQLite、日志或托管控制平面数据库均不会将该值写入 iOS 偏好设置或钥匙串。用户所选的密码自动填充提供商可能依据其自身设置和隐私条款另行存储该值。
- 在本地 Wi-Fi 或 Tailscale 连接下，手机流量直接发送至用户计算机。Tailscale 是独立服务，适用其自身隐私条款。
- 若桌面用户启用可选托管访问，OpenMausBot 会存储账户邮箱地址、内部账户 ID 及计算机安装元数据：不透明安装 ID、不透明客户端 ID、计算机显示名称、操作系统、应用版本、状态和安全时间戳。还会存储不透明的 Cloudflare Tunnel/DNS 资源 ID 和脱敏的运维错误。这些记录仅用于登录、所有权、滥用防范、配置、撤销、支持和可靠性。
- 可选 HTTPS 路由由 Cloudflare 代理至用户计算机上的仅出站 `cloudflared` 连接器。消息、审批、对话响应和屏幕帧在传输中经过 Cloudflare，但不会写入 OpenMausBot 控制平面数据库。Cloudflare 作为 OpenMausBot 的服务提供商，可能依据 Cloudflare 隐私条款处理 IP 地址及连接/请求元数据。
- 连接器令牌保存在桌面操作系统的加密凭据存储中。配对令牌和设备令牌不存储在托管控制平面数据库中。
- 当用户从其他应用的分享面板中明确选择 OpenMausBot，或使用聊天中的附件按钮时，所选文本、链接、图像或受支持文档会发送至用户确认的机器人或房间。图像和文档以生成的名称和仅所有者可访问的文件权限存储在用户计算机的附件目录中。单张图像上限 10 MiB，文档上限 25 MiB，单条消息上限四项且总计 50 MiB。附件达到 512 MiB 后，计算机拒绝新上传，而非静默删除旧对话引用的文件。代理发送的语音消息为 mp3 文件，存放在同一附件目录中，使用生成的名称和相同的仅所有者权限，并计入同一 512 MiB 配额。聊天内所选内容保留在内存中，直至消息发送成功或草稿被丢弃。分享扩展的临时副本在发送完成或取消后删除。若 iOS 在传输中途终止扩展，下次分享面板会话会立即删除被放弃的副本；OpenMausMobile 前台启动时，会删除已存在至少 60 分钟的副本。
- 打开机器人发送的文件链接时，应用会通过所选已认证配套连接向已配对计算机请求该确切文件。应用仅在预览打开期间保留临时本地预览，随后删除。普通网页链接继续在系统浏览器中打开。托管控制平面不存储源文件或其预览。
- 本应用不含广告或分析 SDK，不跨其他公司的应用或网站追踪用户，也不出售个人数据。

本地 HTTP 连接仅应在用户信任的网络上使用。Tailscale 和托管 HTTPS 访问是面向不可信或远程网络的加密替代方案；两者均无法使休眠或关机的计算机变为可访问。

## 保留、控制与删除

取消配对会从手机中移除计算机地址和配对令牌。在 OpenMausBot 的配套设置中撤销手机，会使该设备凭据失效。对话记录的删除由存储该记录的 OpenMausBot 安装实例控制。

退出可选托管访问会停止广播托管地址、撤销计算机安装凭据，并安排删除其 Cloudflare Tunnel 和 DNS 记录。账户邮箱、账户标识符、安装/安全元数据和运维记录在运营和保护服务所需期间保留，否则保留至账户持有人请求删除。出于安全、欺诈防范、争议解决或法律要求，可能保留少量必要记录。

如需请求获取或删除托管账户数据，请提交 [OpenMausBot 支持](https://github.com/milind-soni/OpenMausBot/issues)请求，切勿附带 OTP、配对码、设备令牌、连接器令牌或其他机密信息。维护者将提供私密方式验证邮箱地址的控制权。删除托管账户数据不会删除存储在用户自己计算机上的对话记录。
