# 决策模型

OpenMausBot 可用快速决策模型为机器人做选择。几百毫秒内返回结果，成本不到一分钱。它从不执行实际工作：被选中的机器人仍用自己的引擎跑自己的回合。首个支持的模型是 TypeSafe 的 [Jev](https://typesafe.ai)。

所有配置都在 **设置 → 决策模型**：一个总开关、Jev 密钥（带 **保存** 和 **测试**）、以及每个可执行任务的独立开关。

## 目前能决定什么

**房间内由谁回答。** 响应者设为 **自动（Jev）** 的房间，会把每条未 @任何人 的消息交给 Jev 判断该由谁回答。问题中列出房间的活跃机器人（各带名称、标题和描述），外加"多名成员"选项。读取的状态包括房间名称、成员、最近房间消息（与房间回合使用同一窗口，仅裁剪大小）以及新消息。

- 若某个机器人返回的概率不低于 0.6，仅该机器人回答。
- 若"多名成员"返回 0.6 或以上，所有成员都回答。
- 置信度不足时，交给房间的兜底逻辑：使用变为自动模式前的负责人，否则用第一个成员。这正是当前负责人模式房间的行为。

@提及、`@everyone`、团队目标及其他响应者模式从不询问 Jev。消息直接追加，发送立即返回；仅在房间回合开始时才等待答案，超时 1.5 秒。

由 Jev 选定发言者的回复下方会显示一行小字：*由 Jev 选定 · 94%*。

决策器及其房间任务开启时，新房间默认使用自动模式。已有房间保持原模式。Jev 关闭时，自动模式房间显示一行提示，并按负责人模式回答。

浏览器点击、工具选择和工作运行位置标注为"即将推出"，尚无开关。

## 失败时放行

决策模型绝不阻塞或延迟回合，超出其短暂预算即放弃。无密钥、开关关闭、任务关闭、超时、网络错误、HTTP 错误（401、429、529、5xx），或答案校验不通过（选项不在提供列表中、概率不是数字）时，房间的行为与没有它时完全一致。每个答案在使用前都会校验。

## 记录内容

每次调用模型都会在 `~/.openmausbot/decider-log/YYYY-MM.ndjson` 追加一行（权限 0600）。该日志与 `decisions/` 中的审批日志相互独立。

```json
{"at":"…","seam":"roomRouting","provider":"jev","ok":true,"choice":"<bot id>","pTop":0.94,"margin":0.9,"latencyMs":341,"inputTokens":712,"stateHash":"3f1c…"}
```

日志行绝不包含消息文本、机器人描述或密钥；状态的 16 字符哈希足以识别重复。失败的调用记录原因（`timeout`、`overloaded` 等）和 HTTP 状态码。月度文件按审批日志的保留窗口保存（默认 180 天）。日志保留在本机：工作区备份不包含它。

## 密钥存放位置

- **桌面应用：** 存放在操作系统的加密存储（`credentials.bin`）中，与其他工作区密钥相同。服务器启动时以 `OMB_JEV_API_KEY` 接收；`config.json` 中仅保留空占位符。
- **服务器或浏览器使用：** 存放在服务器自己的 `config.json`（权限 0600）中的 `decider.key` 下。`OMB_JEV_API_KEY` 可覆盖它。
- **Cloud Pro：** 决策已包含，无需粘贴密钥。若用户没有自己的密钥，Cloud 主端使用其中继令牌（`OMB_CLOUD_DECIDER_TOKEN`），仅发送给管理端的中继，绝不发送给 Jev 或 `baseUrl`，且仅用于房间路由和密钥检查（其他任务需要用户自己的密钥）。设置中显示 **已包含在您的 Cloud 套餐中**，总开关默认开启，直到有人关闭。此处保存的密钥始终优先；清除后回退到包含的决策。参见 [cloud-pro.md](cloud-pro.md) 中的"Included Boat computers, voice and decisions"。

密钥只写不可读：`GET /api/config` 仅报告是否已保存及哪些开关开启。引擎绝不继承该密钥，诊断导出会将其遮蔽。保存密钥时会发起一次极小的测试调用；Jev 拒绝的密钥不会被保存。**测试** 按钮按需发起同样的调用。一次房间决策约花费 $0.00003；测试调用更少。

## 关闭方式

关闭 **使用 Jev 进行快速决策**，或清除密钥（Cloud Pro 上清除密钥会回退到包含的决策：关闭开关即可停止）。若要保留 Jev 但停止房间路由，关闭 **房间内由谁回答**。若要停止某个房间的询问，将其响应者设为负责人、**所有人回答** 或 **仅在被提及时**。

## 配置参考

```json
"decider": {
  "enabled": true,
  "provider": "jev",
  "key": "",
  "baseUrl": "https://api.typesafe.ai",
  "jobs": { "roomRouting": true }
}
```

`baseUrl` 指向 Jev 兼容服务器而非 TypeSafe 的服务器。它没有设置界面。必须为 https，或仅限本机的 http。请求发往 `{baseUrl}/v1/systemone`，模型为 `jev-latest`。

## 度量方式

`server/decider/room-routing.eval.test.ts` 会将 53 条带标注的房间消息（`server/decider/fixtures/room-routing.json`）对实时模型回放。除非设置 `OMB_JEV_LIVE_EVAL=1` 并提供密钥，否则跳过，每次运行约花费 $0.002。
