# 桌面到桌面伴侣模式

每个 OpenMausBot 桌面版都能扮演两种角色之一：

- **主机模式**是常规应用。它拥有智能体、对话、凭据、例程和计算机。
- **客户端模式**通过手机应用所用的同一套需认证、默认拒绝的伴侣 API 控制已配对的主机。

角色与平台无关。Windows、macOS 或 Ubuntu 版都可作为主机，任何其他桌面版都可作为其客户端。一次应用安装同一时间只使用一种角色；断开客户端后，该安装会回到主机模式，且不会删除其本地主机数据。

此模式与 **设置 → 远程访问 → 连接到另一台计算机**（也可通过 **服务器** 菜单进入）中的 **自托管服务器** 不同。自托管服务器连接会直接加载远程服务器的 Web UI，使用该服务器自己的浏览器会话。若你要用自定义 HTTPS 域名或 Cloudflare 隧道连接自托管服务器及其 12 位配对链接，请使用该选项。桌面伴侣模式则把内置 UI 和原生集成保留在客户端，通过默认拒绝的伴侣边界发送 API 流量，并提供下文所述的按设备 VPS 查看器和客户端本地 Mac 语音行为。两种连接类型有意不共享凭据。

## 通过安全 HTTPS 配对

1. 在主机上打开 **设置 → 远程访问**，完成 **安全 HTTPS 配对**。
2. 打开配对窗口，主机会显示一个六位验证码。
3. 在客户端上打开 **设置 → 远程访问 → 连接到另一台计算机**，选择 **桌面伴侣**。
4. 输入主机的托管伴侣地址（`https://c-….openmausbot.com` 或 `https://c-….mausbot.si`）和六位验证码。
5. 选择 **配对并切换到客户端模式**。客户端会重启并打开主机的机器人 UI。

HTTPS 地址使用主机的托管出站隧道。TLS 由操作系统验证，客户端无需 Tailscale。HTTPS 有意限制为 OpenMausBot 签发的名称（`openmausbot.com` 或 `mausbot.si` 下以 `c-` 开头加 32 个十六进制字符），这样拼写错误或这些域名下的其他主机都无法收到配对码或已配对设备令牌。0.1.103 及更早的桌面版本只接受 `openmausbot.com` 名称；请更新客户端，以便与地址位于 `mausbot.si` 的主机配对，或通过 Tailscale 配对。

## 通过 Tailscale 配对

1. 在两台计算机上安装 Tailscale，登录同一 tailnet，并保持 MagicDNS 启用。
2. 在主机上打开 **设置 → 远程访问**，开启远程访问，然后打开 **通过 Tailscale 配对** 以显示六位验证码。
3. 在客户端上打开 **设置 → 远程访问 → 连接到另一台计算机**，选择 **桌面伴侣**。
4. 输入主机的完整 `.ts.net` MagicDNS 名称和六位验证码。
5. 选择 **配对并切换到客户端模式**。客户端会重启并打开主机的机器人 UI。

要将该安装切换回来，请打开 **设置 → 远程访问**，选择 **断开连接并使用此计算机**。

## 远程控制 VPS 桌面

桌面客户端可通过任一配对传输方式打开智能体的自托管 VPS 显示。在主机上，于 **设置 → 远程访问** 中为该已配对桌面启用 **云桌面访问**。在客户端上，打开机器人的 **计算机** 面板，选择 **接管控制**。

计算机面板还会显示定期刷新的 VPS 截图。预览和实时控制共用同一按设备权限，默认关闭。VPS 仍不发布任何 VNC 端口。主机会打开其现有的仅回环 SSH 隧道，伴侣创建随机的设备级查看器路径，客户端通过其回环 Electron 服务中继 noVNC HTTP 和 WebSocket 流量。关闭查看器会移除伴侣会话、关闭 SSH 隧道，并将控制权交还给智能体。

远程客户端只能预览、打开和关闭查看器。VPS 预配、替换、休眠、移除、SSH 别名、本地 VM 控制以及主机浏览器界面仍仅在主机上可用。

客户端日历端到端支持计划例程：创建、编辑、移动、调整大小、暂停、删除、立即运行、取消活动运行以及确认失败。计划调用和 webhook 仍仅限主机，在客户端模式中不提供。

远程计算机面板包含主机面板的按智能体 **计划任务** 卡片。它列出该智能体的下一批例程和活动运行，打开完整计划视图，并创建已分配给该智能体的新计划。

Mac 远程客户端支持对任意主机进行听写和实时通话：Apple Speech 在 Mac 本地运行，只有转录文本会通过配对连接传输。当 Mac 客户端选择内置系统语音时，回复语音会在该 Mac 本地合成并播放；ElevenLabs 和 Fish Audio 的回复音频由主机合成并逐字节中继。Windows 远程客户端仍需未来的 Windows 语音转文本实现才能使用麦克风输入。

语音消息附件通过同一中继流式传输：mp3 服务路由在伴侣允许列表中，音频逐字节传输，且 `Range` 请求会被转发，因此播放器可在片段内拖动进度而无需重新下载。

主机必须正在运行且处于唤醒状态。明文 HTTP 仅接受 `.ts.net` MagicDNS 主机名，因为该连接在 Tailscale 的 WireGuard 隧道内加密。原始 IP 地址、LAN 主机名、URL 凭据、路径、查询和片段均会被拒绝。

## 安全模型

配对会在主机上创建独立的设备身份。生成的 bearer 令牌：

- 仅存储在客户端上 Electron 由操作系统加密的凭据文档中；
- 绝不通过 preload 桥返回、插入页面、放入 URL 或写入浏览器存储；
- 在移除浏览器 `Origin` 头后，由仅回环的 Electron 中继注入；
- 仅发送到精确保存的托管 HTTPS 或 `.ts.net` 源；绝对形式请求目标无法将其重定向到别处。

主机伴侣仍是授权边界。其路由列表默认拒绝，会剥离敏感响应字段，并可像其他已配对设备一样从 **设置 → 远程访问** 撤销桌面客户端。交互式桌面访问是独立的按设备能力，默认关闭。客户端模式不暴露仅限主机的设置、本地浏览器界面、本地 VM 控制、插件凭据、破坏性账户撤销或事件检查器。已连接应用可远程查看和授权，而其令牌和执行仍留在主机上。

桌面客户端与已审查的伴侣功能面一致：聊天、房间、流式响应、审批、内联已连接应用授权、搜索、例程、附件，以及主机明确授予该已配对设备的范围狭窄的云/VPS 查看器。扩展桌面客户端必须通过明确审查并添加伴侣路由来完成；不得绕过伴侣 API 或代理完整 harness。

## 运行时形态

```text
desktop renderer
      │ same-origin HTTP/SSE, no bearer
      ▼
Electron relay 127.0.0.1:8798 (fallbacks: 18798, 28798)
      │ bearer injection over verified managed HTTPS or Tailscale/WireGuard
      ▼
host companion :8810
      │ authentication + route allowlist + response scrubbing
      ▼
host harness 127.0.0.1:8799
```

客户端模式激活时，Electron 不会启动其本地 harness、伴侣 sidecar、计算机使用守护进程或浏览器引擎主机。渲染器仍使用普通的同源 API 调用和 `EventSource`，因此现有 UI 和流式存储无需了解或处理第二种传输方式。
