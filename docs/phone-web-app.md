# 安装手机 Web 应用

浏览器 UI 可以添加到手机主屏幕。它会在独立窗口中打开，并使用与浏览器相同的工作区、对话和配对。

1. 在 iPhone 的 Safari 或 Android 的 Chrome 中打开工作区的 **HTTPS Web 链接**。可使用已有的托管地址、Tailscale HTTPS 地址或你自己的 HTTPS 反向代理。手机无法通过 localhost 链接访问电脑。远程访问和配对参见[自托管](self-hosting.md)。
2. 使用正常的配对流程将浏览器与该工作区配对。
3. 在 iPhone 上，打开 Safari 的**分享**菜单，选择**添加到主屏幕**，如果 Safari 提供**作为 Web App 打开**选项则保持启用，然后点击**添加**。在 Android 上，打开 Chrome 菜单，选择**安装应用**或**添加到主屏幕**。
4. 从主屏幕打开 **OpenMausBot**。如果该浏览器将主屏幕应用存储在独立空间中，也需要为这个新窗口配对。安装本身不会授予工作区访问权限。

安装后的启动地址是工作区根路径；配对码和 URL 令牌不会保存在 manifest 中。如果访问权限过期或设备被撤销，请使用新的配对邀请。

服务器必须正在运行且可访问。此 Web 应用不提供离线聊天、推送通知或原生手机电脑控制。
