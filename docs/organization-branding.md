# 组织品牌

组织管理员可以在 Admin → Branding 中上传一个 Logo 和最多 24 个共享机器人图标。支持 PNG、JPEG 或 WebP，每次上传不超过 5 MB。Admin 会在保存前调整图片尺寸；标准化后的集合限制为 128 KiB。

成员照常通过 Settings → Organization 连接。Logo 会显示在侧边栏和 Organization 设置中。共享图标会出现在每个机器人的头像自定义选项中，与常规上传和吉祥物选项并列。

已连接的桌面应用会在现有的会话心跳中刷新品牌。使用 Organization 设置中的 Refresh 可立即获取更改。旧版 Admin 不返回品牌信息，因此应用外观保持默认不变。个人用户无需登录。

选择共享图标会将其副本存储为普通的本地头像附件。即使管理员之后移除该图标或成员断开连接，它仍会保留在该机器人中，包括在工作区备份中。断开连接会隐藏组织 Logo 和共享库，但不会删除个人头像。品牌不会更改已安装的应用名称、Dock/开始菜单图标、模型权限或身份验证。远程工作区页面无法读取本地桌面的组织品牌。
