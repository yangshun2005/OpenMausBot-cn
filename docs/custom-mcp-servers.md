# 自带 MCP 服务器

打开 **插件 → MCP 服务器 → 添加服务器**，即可让你信任的 MCP 服务器为你的机器人提供工具。服务器分两种：

- **运行命令** —— 本地 stdio 服务器。填入可执行文件，每个参数单独一行，环境变量按 `KEY=value` 添加。
- **连接 URL** —— 远程服务器。粘贴地址；若需要令牌，则作为请求头添加（`Authorization: Bearer …`，每行一个请求头）。大多数服务器使用 **Streamable HTTP**；仅当旧服务器文档说明 `/sse` 端点时才选 **SSE**。

OpenMausBot 保存新服务器时默认关闭。用 **测试** 启动命令（或连接地址），完成 MCP 握手，查看它声明的工具。然后启用它。兼容的机器人在下一次任务时即可使用，无需重启应用。

URL 服务器的令牌放在请求头里，绝不放在地址里。

### Whop

在插件中，找到 **Whop**（与 Gmail、Slack 等应用并列），点击 **连接**。内置卡片使用 Whop 官方托管的 MCP 端点，并打开 Whop 的浏览器登录；无需 API 密钥、本地 CLI 或 Composio 连接。登录成功并发现工具后，它会启用该连接。首次设置被取消或失败时保持关闭，可重试，无需再添加服务器。

打开 Whop 卡片上的 **机器人访问**，进入各机器人现有的访问设置。设为使用所有已启用 MCP 服务器的机器人会自动继承该连接；显式选择服务器的机器人必须包含其服务器名。下一次任务使用该选择。Whop 也会出现在 **已连接** 过滤器中。**断开连接** 会禁用连接并登出；保存的条目仍可重新连接。官方 HTTP 端点下已有的自定义 Whop 条目会被识别，而非替换。

Whop 目前请求对你 Whop 账户可管理的所有企业拥有管理员权限，其自身的重大操作确认仍然生效。参见 [Whop MCP 官方文档](https://github.com/whopio/whop-mcp-server)。这是可选的连接工具，不影响 OMB 的订阅计费。

### 要求你登录的服务器

有些 URL 服务器不需要令牌；它们要求你用浏览器登录（OAuth）。当 **测试** 收到 HTTP 401，且响应指向服务器的登录信息（先是 RFC 9728 受保护资源元数据，再是授权服务器自身的元数据）时，服务器会显示 **需要登录** 和 **登录** 按钮。登录会在浏览器中打开提供商的页面，你批准后返回 OpenMausBot。服务器随后显示 **已登录**，测试会列出其工具。

- **哪些服务器可用。** 授权服务器必须支持 PKCE 与 S256。若它允许应用自行注册（动态客户端注册），OpenMausBot 会为每次登录注册一个新应用。若它只接受预先注册的应用，请按下文添加该应用。没有登录信息的 401 保持原提示：检查地址和请求头。
- **在哪里登录。** 任何使用 OpenMausBot 的地方：运行它的电脑上，或另一台电脑的浏览器中（My Cloud、托管工作区、你自己的服务器）。见下文。
- **机器人从不登录。** 需要登录的服务器在有人从此页面登录前，会被排除在所有轮次之外。已登录的服务器会用 `Authorization: Bearer …` 替换你设置的任何 `Authorization` 请求头，因此所有能访问 URL 服务器的引擎都能使用它。
- **令牌单独保存。** 它们存放在 `~/.openmausbot/mcp-oauth.json`（仅所有者可读），绝不写入 `config.json` 或 API 响应，也不包含在工作区备份中。它们属于服务器的地址：更改地址或删除服务器会丢弃它们。**登出** 会在服务器支持时撤销令牌，然后遗忘它们。
- **刷新。** 令牌在过期前不久刷新。若服务器拒绝刷新，服务器回到 **需要登录**。

#### 从另一台电脑登录

在运行 OpenMausBot 的电脑上，浏览器会回到 `127.0.0.1`。在另一台电脑的浏览器中，该地址指向你自己的电脑，那里没有 OpenMausBot，因此登录需另寻他路：

- **通过 https（My Cloud、托管工作区、https 后的服务器）。** 当服务器允许应用自行注册时，浏览器会回到你使用 OpenMausBot 的地址，路径为 `/mcp-oauth/callback`，标签页显示 **已登录。你可以关闭此标签页并返回 OpenMausBot。** 无需复制任何内容。Whop 就是这样工作的。该地址是服务器的公开地址（Cloud 或托管工作区自身的地址、已连接域名，或 `OMB_PUBLIC_URL`）——当你在其上时；若未设置，则是你浏览器所在的 https 地址。若你通过服务器未列出的 https 地址访问它，登录会改为回到其列出的公开地址。
- **否则，粘贴一个地址。** 对于预先注册的应用（它总是回到注册的 `127.0.0.1` 地址）、不愿为你的 https 地址注册 OpenMausBot 的服务器，或通过纯 http 访问的服务器，登录面板会提示：*批准后，浏览器会显示一个无法加载的页面。复制该页面的完整地址并粘贴到此处。* 复制 **地址栏中的完整 URL**，粘贴到 **重定向 URL**，选择 **完成登录**。无法加载的页面是正常的：它指向你的电脑，而 OpenMausBot 在服务器上。无需端口转发。

在运行 OpenMausBot 的电脑上，同样的粘贴步骤位于 **从另一台电脑登录？** 下，用于 SSH 隧道或别处的浏览器。**打开登录页面** 可在浏览器阻止首次尝试时重新打开批准页面。

请对重定向 URL 保密。在启动流程的同一 OMB 浏览器/会话中，五分钟内完成流程。取消或登出会结束待处理的流程；URL 不可重用，且回到 https 地址仅对该次登录有效一次。

#### 需要预先注册应用的服务器

企业身份提供商（例如 Microsoft Entra ID）和部分托管服务器不允许应用自行注册。在提供商处注册应用，然后编辑服务器并填写 **登录应用**：

- 该应用的 **Client ID**。设置 Client ID 后，OpenMausBot 以该应用身份登录，不再注册新应用。
- **Client secret**，仅用于机密应用。它像请求头值一样只写：保存在 `config.json`，不再显示，且仅发送到授权服务器的令牌端点（HTTP Basic，或当服务器仅列出 `client_secret_post` 时放在表单中）。它绝不复制到 `mcp-oauth.json`。留空则保留已保存的值；**移除已保存的密钥** 会删除它。
- **Scopes**，以空格分隔。它们替换服务器声明的 scopes；当你的提供商需要 `offline_access` 来签发刷新令牌时，请添加它。

保存后，编辑器会显示需向应用注册的重定向 URI：`http://127.0.0.1:<port>/mcp-oauth/callback`，其中端口对服务器的地址是固定的。使用已注册应用登录时始终使用该端口；若被其他程序占用，登录会停止并提示。更改 Client ID 或 scopes 会使服务器登出；同一应用的新密钥不会。

### 示例：让你的机器人进行网络搜索

一个不错的入门 URL 服务器是 You.com 的搜索服务器，因为免费档完全不需要令牌。添加一个 URL 服务器，地址为

```
https://api.you.com/mcp?profile=free
```

请求头留空，按 **测试** —— 握手完成，服务器声明 `you-search`（网络搜索）和 `you-discover`（其他 MCP 服务器的目录）。免费档为只读，限速每天 100 次搜索；没有密钥，因此不存储任何密钥。启用服务器后，每个兼容的机器人在下一次任务时即可搜索网络 —— `you-search` 的结果像其他工具结果一样，通过批准卡片返回。

若免费额度太小，[you.com/platform](https://you.com/platform) 会签发配额更高的 API 密钥，并提供 `you-contents` 工具用于整页提取。添加相同地址但去掉 `?profile=free`，并加一行请求头 `Authorization: Bearer <your key>` —— 密钥像其他请求头值一样只写保存。`you-research`（多步带引用的报告）由它自己的专用服务器 `https://api.you.com/mcp/research` 提供 —— 用相同方式、相同请求头添加。

### 导入并按机器人选择工具

**粘贴配置** 接受 `mcpServers` JSON 块、服务器名映射或单个命名条目 —— 命令和 URL 服务器皆可，格式与 Claude Code、Cursor 和 Claude Desktop 写出的相同。导入是全有或全无，拒绝已存在的名称，且添加的服务器默认关闭 —— 即使粘贴的配置写着已启用。它不会安装、执行或连接它们。显式测试后，再启用你信任的服务器。

打开机器人的 **工具 → 访问 → MCP 服务器**，可缩小提供给它的已启用全局服务器范围。现有机器人保留所有已启用的全局服务器，直到你选择子集；全部关闭则一个都不用。**使用所有已启用的服务器** 恢复默认，包括未来的新增。更改此选择前，请停止该机器人所有正在运行的轮次；下一次直接或频道轮次会使用新列表。该列表不过滤项目本地的 `.mcp.json` 文件，也不是 shell 沙箱。单个工具的批准取决于引擎和批准模式。

### 拥有数百个工具的服务器

有些服务器提供的工具多到模型无法一次有效读取：Whop 列出了 425 个。Claude Code 和用自己账户登录的 Codex 会按需查找工具，因此它们像以前一样获得整个服务器。其他引擎会在每条消息中读取每个工具的描述，而 API 模型引擎在 128 个工具时停止。因此，对于 API 模型、Pi 以及使用 ChatGPT 套餐的 Codex 上的机器人，大型 URL 服务器会显示为三个工具：一个搜索其工具，一个读取某工具的确切输入，一个按名称运行工具。搜索工具会逐区域说明服务器涵盖的内容。

当服务器拥有超过 40 个工具，或工具描述超过约 100,000 个字符（大致是 Claude Code 自行开始搜索的阈值）时，即视为大型。较小的服务器照旧列出。无需配置。机器人的工具选择仍然有效：它只能查找和运行你为它选择的工具，批准卡片会指明正在运行的工具，而非搜索。大型 URL 服务器在机器人轮次中也有 30 秒启动时间，与 **测试** 按钮给的一致；命令服务器保持八秒。

已知限制：

- **使用 ChatGPT 套餐的 Codex，在“为我批准”模式下，每次调用都会询问。** Codex 允许服务器的只读工具无需询问即可运行，但这里每个工具都通过那个运行所有工具的工具运行，无法携带各工具自身的只读提示。每次 Whop 调用都会显示一张卡片，指明工具名。
- **命令服务器尚不支持搜索。** 只有 URL 服务器支持。拥有数百个工具的命令服务器仍整体列出，而 API 模型机器人在一轮中拒绝超过 128 个工具。

### 哪些引擎能访问哪些服务器

| 服务器 | Claude Code 机器人 | Codex 机器人 | ACP 机器人（Cursor、Grok、Kimi 等） | API 模型机器人 |
| --- | --- | --- | --- | --- |
| 命令（stdio） | 是，通过结果门 | 是 | 是 | 是 |
| URL，Streamable HTTP | 是 | 是 | 是 | 是 |
| URL，SSE | 是 | 是 | 是 | 是 |

除 Claude Code 外，所有引擎都通过 OpenMausBot 自己的连接器访问 URL 服务器，与 **测试** 使用的是同一个，因此通过测试的服务器在聊天中也能用。有些服务器会拒绝任何它不认识的握手字段，而引擎自带的 MCP 客户端会添加此类字段：自行连接的机器人对一个通过测试的服务器，每个工具都得到“未找到工具”。Claude Code 仍自行连接，因为它的握手只含 MCP 规范定义的字段。

通过连接器，服务器对某次调用自身的错误（缺少参数、未知 id）会带着其代码和文字到达机器人，以便它修正调用；服务器的地址和请求头值会先从中移除，连接失败则保持通用。工具调用可耗时与引擎允许的一样长（连接器不自行添加截止时间，除了无法自行搜索工具的机器人所用的工具搜索为两分钟）。HTTP 401 会告诉机器人重新发送消息（消息开始时刷新登录），若仍失败，则重新登录或检查插件 → MCP 服务器中该服务器的请求头值。

## Claude 机器人看到什么，以及“同时使用我的 Claude Code MCP 服务器”开关

使用 Claude 引擎的机器人获得其所有者给它的工具和指令：上述服务器、它的集成（电脑、浏览器、代理、手机），以及它自己项目的 `<cwd>/.mcp.json`。默认情况下，它 **不** 继承本机的 Claude Code 设置 —— 你的用户或本地 Claude 配置中的 MCP 服务器和 claude.ai 连接器、你的技能和代理、你的 hooks，以及你的个人 `~/.claude/CLAUDE.md`。这些曾被挂载到每个机器人的每一轮（一台实测桌面增加了 407 个工具，每次模型调用约 10k tokens），且机器人可访问。相比之下，Codex 机器人一直读取 `~/.codex/config.toml` 中的 MCP 服务器，这就是两个引擎看起来不同的原因。

若你希望 Claude 机器人也看到你自己的 Claude Code MCP 服务器，请在 插件 → MCP 服务器 顶部打开 **同时使用我的 Claude Code MCP 服务器**。开启后，每个 Claude 机器人还会在每条消息中加载你 Claude Code 配置中的服务器和连接器；技能、hooks 和个人 `CLAUDE.md` 仍不包含。工具越多，每条消息的 tokens 越多，因此除非需要那些服务器，否则保持关闭 —— 给机器人提供服务器的推荐方式仍是本页面或机器人项目的 `.mcp.json`。

该开关会去掉 CLI 标志 `--strict-mcp-config`（Claude Code 1.0.60+），同时保留 `--setting-sources project`（1.0.122+）。OpenMausBot 进程上的环境变量 `OMB_CLAUDE_INHERIT_USER_CONFIG=1` 仍是回到旧启动方式的完整逃生舱：它为每个 Claude 机器人恢复一切，直到你移除它。该 harness 还用 `--autocompact`（2.1.122+）选择会话的压缩窗口。OpenMausBot 在列出引擎时（应用加载、引擎页面、更新后）读取 `claude --version`，只向接受该标志的 CLI 传递每个标志，因此较旧的 CLI 仍能工作 —— 只是缺少它之前没有的控制项 —— 引擎页面会显示更新通知及确切命令。`claude update` 可清除它。

## 当你的组织管理 MCP 服务器时

若此电脑连接到组织（设置 → 组织）且其管理员关闭了自定义 MCP 服务器，则只有名称或地址在组织批准列表上的服务器才能到达机器人。其他已配置的服务器仍留在你的列表中，标记为 **由** 你的组织 **管理**，但机器人不会获得它们，且“同时使用我的 Claude Code MCP 服务器”开关无效。**粘贴配置** 关闭，**添加服务器** 只接受已批准的服务器。不会写入 `config.json`；断开组织连接会按你的配置恢复列表。未连接组织时，这些都不适用。

地址条目仅限 HTTPS。主机逐标签比较，其中 `*` 代表一个或多个完整标签（`https://*.example.com/mcp` 匹配 `https://a.example.com/mcp`，绝不匹配 `https://evil.test/x.example.com/mcp`），路径单独比较，其中 `*` 匹配任意内容。

限制：个人 **Codex** 引擎还会从你自己的 `~/.codex/config.toml` 加载 MCP 服务器，OpenMausBot 不过滤这些。必须阻止它们的组织可以只允许公司模型，或将个人 Codex 从其引擎列表中移除。公司 Codex 使用自己独立的 home，不含你的 `config.toml`。

## 高级：编辑文件

同一注册表位于 `~/.openmausbot/config.json`：

```json
{
  "mcpServers": {
    "notes": {
      "command": "npx",
      "args": ["-y", "@example/notes-mcp"],
      "env": { "NOTES_TOKEN": "…" }
    },
    "docs": {
      "type": "http",
      "url": "https://mcp.example.com/mcp",
      "headers": { "Authorization": "Bearer …" }
    },
    "corp": {
      "type": "http",
      "url": "https://mcp.corp.example/mcp",
      "oauth": { "clientId": "…", "clientSecret": "…", "scopes": ["api://corp-mcp/read", "offline_access"] }
    }
  },
  "features": { "claudeUserMcp": false }
}
```

`type` 为 `http`（Streamable HTTP，默认）或 `sse`。`oauth` 是可选的登录应用；`clientSecret` 和 `scopes` 可省略。若手动编辑文件，请重启 OpenMausBot。每个引擎能挂载自定义 MCP 服务器的机器人在下一次任务时获得已启用的工具。

## 保障安全的规则

- **默认使用权限卡片。** 自定义服务器从不预先批准：在 Claude 上，其工具经权限代理进入允许/拒绝卡片；在 Codex 上，它们保持按需批准策略；ACP 引擎转发代理自身的权限请求。内置项保持预先静默 —— 只有 *你的* 服务器会询问。
- **保留名称被拒绝**（`computer`、`agents`、`composio`、`browser`、`phone`、`dweb`、`ogb` 等），因此自定义条目绝不会遮蔽内置工具面。名称为小写字母/数字/`_`/`-`，最多 32 字符，以字母开头。
- **一个坏条目绝不会拖垮整个集群。** 无效条目被跳过并记录原因；其余仍会挂载。
- **凭据在 UI 中只写。** API 返回环境变量和请求头名称，绝不返回值。将现有值留空则保持保存；删除其行则删除它。
- **凭据
